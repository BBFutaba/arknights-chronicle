# 列传概述须知

项目：明日方舟编年史，《明日方舟》剧情的编年体史书。所有命令在项目根目录运行。你负责写一批人物列传的概述。

先读 `data/annals/写作规范.md` 的「书法」「列传」两节，再看 `data/annals/列传.md` 里 `@传 霜星`、`@传 陈`、`@传 赫德雷` 三篇，文风以它们为准。

每个人这样做：
1. 运行 `python -X utf8 -m pipeline.annals zhuan <名字>`，看此人列传收录的各条（纲、目）和「其他出场」。
2. `data/annals/列传.md` 里此人已有的概述，原文保留，只在需要时把新事实按时间插入，后面的事接着写，另起段落。还没有概述的，从头写：第一句「某，身份。」（可参照 `data/annals/人物志/*.md` 里此人那一行），其后按时间写。
3. 只写这些条目已经证实的事，不查剧本，不推测，不评论，不预告后事。「」引语只用条目里已有的原话。人物的称呼用目里的写法；同一人的别名见 `data/annals/别名.md`。不要写「见某条」之类的参见。书法用词照规范（战死、某杀某、病逝、击败……）。
4. 新增部分的篇幅：主角（条目十条以上）三百至五百字；一般一百至三百字；只有一两条的五十至一百五十字。写的是此人的经历线索，不是逐条复述。

写到任务指定的文件，格式：

```
@传 名字

此人完整的概述（已有部分＋新增部分），可分段。

@传 下一个名字
……
```

只写这个文件，**不要改 `列传.md` 和其他文件**，也不要运行 `build`。交回时一句话说明写了几篇，并列出条目里发现的问题（事实矛盾、错标归属），没有就不写。
