# 合并须知

项目：明日方舟编年史。人物页按名字建，同一个人可能分成几页。别名表 `data/annals/别名.md` 负责把它们合起来。你来判断候选里哪些确实是同一个，并给出原文出处。**只写结果文件，不改别的。**

## 判断标准

**要合并**（同一个人或同一个存在，原文可证）：
- 本名和代号、化名、昵称、曾用名：如 弑君者 = 柳德米拉、行箸 = 宁茵。
- 同一人的变体干员：如 凯尔希·思衡托 = 凯尔希。
- 巨兽和它唯一的代理人或分身，原文写明是一体的：如 耶拉 = 耶拉冈德、矩 = 矩兽。

**不合并**：
- 共用立绘的不同人。立绘常被复用，也常有人说话时画面上还留着别人。候选里的立绘数字只是线索，**不是证据**。
- 泛称和职务：酒吧老板、人事专员、医生、村长。同一个词在别处可能是别人。只在一组剧情里、原文明说就是某人的也不必合。
- 多人先后担任的头衔：教宗、魔王、王酋、大审判官。除非原文和数据都表明全书只指一人。
- 岁的代理人之间、代理人和岁之间：十二位各有人格，不并成一个词条。巨兽有多个代理人的都不并。
- 梦境、推演、戏中人物、互斥结局里的身份。例如洛伦茨造的梦里，米格鲁的立绘被用于别人。
- 拿不准的，放进「存疑」，写明为什么。

## 怎么查

- `python -X utf8 -m pipeline.annals show <分集id> [起 止]`、`find "<词>" [组id]`、`rawfind "<词>"`。候选里的「例」是原始文件行号，和 `show` 的行号未必相同，引用时一律用 `show` 的行号。
- 档案：`python -X utf8 -c "import json;c=json.load(open('site/data/characters.json',encoding='utf-8'))['<名字>']['profile'];[print('##',s['title'],chr(10),s['text']) for s in c['sections']]"`。
- 人物当前有哪些别名：看 `site/data/characters.json` 的 `aliases` 和 `data/annals/别名.md`。已合并的不用再列。
- 不要只看一条线索就下结论，要看到原文里把两个名字连起来的话：有人当面叫破、自述、档案写明、同一场景里称呼切换。

## 写什么

结果文件每行一组，用制表符分隔：

```
合并	名字甲	名字乙	类型	出处	原话
存疑	名字甲	名字乙	理由
不合并	名字甲	名字乙	理由
```

- 类型：本名、化名、昵称、变体、分身。
- 出处写 `分集id:行号` 或 `档案 名字 栏目`，原话一字不差、不超过四十字，要能看出两个名字是同一个。
- 不要写谁是正名，主编统一定。
- 「不合并」只列看着像、容易被误并的，普通的共用立绘不用列。

## 交回的报告（中文，简短）

第一行：看了几组候选，合并几组，存疑几组。然后列最重要的五到十组，和你认为主编要看的问题。不要编造出处。
