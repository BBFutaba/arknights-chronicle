# 博物志核对须知

博物志第一、二轮是别的 agent 写的。你是核对人，**没有参与撰写，默认别人可能读错了**。先读 `data/annals/博物志须知.md`。命令在项目根目录运行。

## 要做的事

逐条读分给你的文件，每条做这几件：

1. **核事实。** 【释】【说】【沿革】里具体的说法，对照原件核。不是每个字都查，优先查：数字、年份、制度名、地名、谁说的、「凯尔希批道」这种归属、远古和神秘相关的说法。
   - 《大地巡旅》：`Raw Data/大地巡旅/全文.txt`（OCR 有错字，每页以 `=== PDF n | 书页 nnn ===` 开头），页图 `Raw Data/大地巡旅/页/p-NNN.jpg`（PDF 页 = 书页 + 8，个别有偏差）。批注只看图。勘误 `Raw Data/大地巡旅/勘误.txt`。
   - 影片：`Raw Data/视频/字幕/`。
   - 游戏文本：`python -X utf8 -m pipeline.annals rawfind "词"`、`show <分集id> [起 止]`。
2. **查过头。** 一个人的话写成事实；集成战略文本、传说、宣传、玩笑当成史实；编者替他们下结论；没有出处的话（可能是作者凭记忆写的，严查）。
3. **同步书稿。** 书稿刚整补过，很多说法改了。条目里引书稿的地方（【考异】里写「书稿」「外纪」「前纪」「ev0xxx」的，以及【见】）要和现状一致。各卷现状 Grep 对应的 ev 编号就能看到。已知要同步的线索在 `Raw Data/整补线索.md` 和 `C:\Users\acgnm\AppData\Local\Temp\claude\37b680ec48657c91\65b05bb5-ddeb-45dd-8a42-aa6074d7efba\scratchpad\列传补.md`（搜「博物志」）。
4. **补漫画。** 漫画归档后才有这些材料，第一轮没用上：`Raw Data/漫画/*/归档.md`（不用《火与路》）。Grep 条目名，有能帮读者理解这个词的内容才补，一两句，用 `@漫` 引。比如炎魔碎片和伊芙利特（《莱茵生命》）、精英干员称号的来历（《启程》，和 S.W.E.E.P. 资料并列）、卡兹戴尔的安魂节（《塞茜莉亚的安魂寻旅》）、黑钢对感染者的措施（《黑钢》）。
5. **联动不入。** 不能用的分集前缀：act17d0、act32side、act24side、act36side、act45side、act50side、act54side、act13mini。发现就删，上下文改通。
6. **改名和叫法。** 「结晶纪元」只作别名，正文用「结晶时代」。

## 怎么改

- 发现问题**直接用 Edit 改你这个文件**，改之前要看过依据。只改你这个文件。别的文件的问题写进报告。
- 短引要一字不差。OCR 有错字，改短引前看图。
- 文风别动，不要因为喜好重写。埃里克森和凯尔希的口吻要留着。
- 修完 `python -X utf8 -m pipeline.annals check <文件>`，无 `!`。不运行 build，不做 git 操作。
- 一条消息并行读几张图，不要一张一条消息。
