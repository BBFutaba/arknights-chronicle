# 明日方舟编年史 · 写作规范

写卷稿前读一遍本文和《凡例》，再看一眼 `data/annals/1096/全年.md` 的成稿，文风以它为准。写完后运行 `python -m pipeline.annals build`，在网页「编年史」页查看效果。

在项目根目录 项目根目录 运行（Bash：`python -X utf8 -m pipeline.annals ...`）。

## 稿件格式

一卷是一个目录 `data/annals/<年份>/`，里面可以有多个文件。每个文件由若干条目组成，每条以 `@条` 开头：

```
@条 ev0536
【纲】**清晨七时五十五分，……。**

【目】……

【人物】[[陈]] · [[诗怀雅]]

【原文】

@引 main_5_level_main_05-01_beg 12-18 「锚点原文」

【考异】……
```

`@条` 后面先写事件编号，再按需要加选项，用空格隔开：

| 写法 | 含义 |
|---|---|
| `@条 ev0549,ev0550` | 几件事其实是同一场景、分开写会重复时，合成一条。一般还是一事一条 |
| `@条 ev0516 是岁:乌萨斯` | 只知年份，放到卷末「是岁」的这个地区下 |
| `@条 ev0536 事:切尔诺伯格-龙门事件 传:陈` | 归属：这条是哪件事的一环、哪个人物列传的一笔，见「收录标准」。可以写多个，用逗号隔开 |
| `@条 ev0611 系:1097-11-01` | 改系，见「系日以原文为本」 |
| `@条 ev0647 系:1097-11 月末` | 只知月份的条目默认排在当月各日之前；加 `月末` 排到当月各日之后 |
| `@条 ev0660 季初` | 只知季节的条目默认排在该季代表月之后（春→三月、夏→七月、秋→八月、冬→十一月）；加 `季初` 排到这几个月之前 |
| `@条 ev0601 附` | 附记：只书纲 |
| `@条 ev0526 存目` | 存目：不入正文，只在卷末列目，写明不录的理由 |
| `@条 补:凯尔希纵弑君者 系:1097-01-05` | 补条：PRTS 年表没有、原文里有的事，见「补条」 |

- **不要写 `#` 标题。** 月、日标题由程序按系日生成，条目按日期排序，同日的按 PRTS 年表的先后。
- 是岁的地区用国名或大势力名：罗德岛、乌萨斯、炎、维多利亚、哥伦比亚、卡西米尔、谢拉格、拉特兰、叙拉古、萨尔贡、莱塔尼亚、阿戈尔、米诺斯、雷姆必拓、伊比利亚、卡兹戴尔……
- 字段之间空一行。没有内容的字段整个不写（例如无可考异就不写【考异】）。

## 收录标准

编年史不是 PRTS 年表的复述。一件事值得记，是因为它推动了别的事，或塑造了某个人。凡是要立条的事，至少要有下面一种推力：

| 推力 | 说明 | 例 |
|---|---|---|
| **事之因果** | 是某件事的前因、起因、结果，或促成了它 | 罗德岛议定营救博士（切城之役的起因）；龙门近卫局大楼失守（陈夺回大楼的前因） |
| **人之成长** | 关乎某人的起源、身份塑造、理念认同 | 温米被阿兰娜收护（温米的来历）；别乔克目睹父母受刑（折桠的起点）；炎客从 W 口中得知害他旧部全灭的人的下落（他此后去向的动因） |
| **世界格局** | 势力的兴衰、制度的更替、地缘的变化 | 卡兹戴尔军事委员会掌控伦蒂尼姆；莱茵生命十科并立 |

据此，每条 PRTS 事件有三种去处：

| 去处 | 条件 | 写法 |
|---|---|---|
| **立条** | 有上述推力，且能标出**归属**：是某件纪事本末的一环（`事:`），或某篇人物列传的一笔（`传:`） | 纲目俱全。大事（关乎国家势力兴衰、主要人物生死去留）目可到四百字，原文两三段；常事目一百五十至三百字，原文一段 |
| **附记** | 有一点推力，但不足以成为哪件事或哪个人的一环；或者剧本不载、只有设定集或网页文案可据 | `附`：只书纲，必要时附一两句考异；网页上以小字附在当日 |
| **存目** | 对人和事都没有推力：新闻发布会、赛程公告、例行通报、只关乎幕后制作的事等 | `存目`：只写一句纲作为标题，考异里写明不录的理由；不入正文，列在卷末「存目」 |

- 立条而标不出归属的，说明它还不够格：或者补上归属，或者降为附记或存目。`check` 和 `build` 会列出这类条目。
- 纪事本末的 `@线` 会把一条故事线上的条目自动列为候选，但真正的归属以条目上的 `事:` 为准；一条写了 `事:`，就只算它写明的那几件事。
- 附记和存目默认不计入纪事本末和列传。附记确是某件事的一环（多为只见于书外的事，按凡例只书纲）时，写明 `事:本末名` 就收入该件本末；存目始终不收。
- 拿不准时，先问：删掉这一条，读者会看不懂后面的哪件事、哪个人吗？看得懂，就是附记或存目。

## 系日以原文为本

PRTS 年表的日期是社区据剧情推定的，只是一家之言。系日以原文为本，PRTS 作参照：

- 立条的事件，【考异】里要写明日期在原文中的依据：场景抬头、人物说的「昨晚」「三年前」、档案里的年份等。原文与 PRTS 相合的，一句带过即可。
- 原文有**明确证据**与 PRTS 不合时，以原文为准改系：在 `@条` 后写 `系:年-月-日`，也可以写 `系:1097-01`（只到月）、`系:1097-秋`（季节）、`系:1097-02~04`（跨月）。考异里写明依据和 PRTS 原系何日；网页上会注明「PRTS 系于某日，今改系」。
- 证据只是暗示（原文作「似」「或许」、要靠推算才得出）时不改，在考异里说明。
- 原文毫无日期依据的，才从 PRTS，考异里写「原文不书日期，从年表」。
- **不同记载年份不一，两说并存，不硬选。** 同一件事，剧情、档案、书、影片、年表或由原话推算出的年份对不上时，两个时间都接受：条目系在一处（一般不动现有系年），纲里括注「一说某年」，考异写「两说并存」，分别标明每个年份的来源，再用一两句简单点评（差在哪、哪边根据硬些、碍不碍后事），不必定谳。列传里写到这一年的，也括注。以下不算：只差月日；第二个数说的不是同一件事；整数约数（十年、二十年、五十年）只差一两年的，考异写明两个年份，纲不加注；年表与原文明文相抵、年表别无所本的，仍按上面改系，网页会同时显示年表原系。
- 改系到别的年份，条目要放到那一年的目录里。

## 补条

PRTS 年表也有漏列的事。读原文时发现对人或事有推力、年表却没有的事，补立一条：

- 写成 `@条 补:<简短名称> 系:年-月-日`，名称在全书中不能重复，例如 `补:凯尔希纵弑君者`。
- 同一天里，补条默认排在年表各条之后；要排在某条之后，加 `次:ev编号`，例如 `@条 补:监察司观战 系:1097-01-05 次:ev0549`。
- 必须有系日（`系:`）、原文（至少一段 `@引` 或 `@档`）和【考异】，考异里写明日期依据，不必提年表。只知年份的，写 `系:1097 是岁:哥伦比亚`。
- 补条都是立条，不能写成附记；推力不够立条的，不补。
- 一样要标归属。
- 补条之前先查一遍：这件事是不是已经写在某条 PRTS 事件的【目】里了。已经写了就不必另立。
- 连续的情节合成一条：一件事的几个环节写成一条下的几组纲目（一条不超过四组），不拆成几条补条。只有日期不同、或与别的条目要穿插排序时才分开。一卷的补条一般不多于年表事件。

## 书法

用词只求中性一致，不寓褒贬。下表左栏是要用的写法；右栏的词只能出现在引号里的原话中。

| 事 | 写法 | 不用 |
|---|---|---|
| 在战斗中死去 | 战死 | 牺牲、阵亡、殒命、捐躯 |
| 指明为谁所杀 | 某杀某；某为某所杀 | 惨遭毒手、被害 |
| 经判决或命令处死 | 处死 | 处决（引原话除外） |
| 自杀 | 自尽 | 自戕、轻生（引原话除外） |
| 因病而死 | 病逝 | 病故、病殁 |
| 死于灾害、事故、爆炸 | 死于某（如「死于天灾」） | 遇难、罹难、丧生、身亡 |
| 死因不明或原文不写 | 死；原文没写死，就照原文写（「没有回来」「下落不明」），在考异说明 | 死去、而死、殒、殁 |
| 官方宣告死亡而其实存活 | 被宣告死亡 | 假死（除非本人有意诈死） |
| 战斗胜负 | 击败（胜负已分）、击退、击倒、重创 | 斩杀、歼灭（引原话除外） |
| 擒人、带走人 | 俘获、劫走、救出、带走 | 绑架（剧中定性如此时可用，并加引号） |
| 城池、据点 | 攻陷、占据、夺回、撤出 | 解放、沦陷（引原话除外） |
| 加入、离开组织 | 加入、离开、叛出、被逐 | 投敌、背叛 |

其他：
- 人物和组织的评价（「暴徒」「英雄」「阴谋」）只出现在引号里，并说明是谁说的。
- 推测用语（「或」「疑」「似」）只用于考异；纲目只写确定的事。
- 时刻：凌晨（零至五时）、清晨（五至八时）、上午（八至十一时）、中午（十一至十三时）、午后（十三至十八时）、傍晚（十八至十九时）、夜（十九至二十四时）。
- 罗德岛：指组织写「罗德岛」，指舰船写「罗德岛本舰」。

`check` 和 `build` 会列出纲和目里用到上表「不用」一栏词语的地方，引号里的原话不算。
- **不猜人物身份。** 漫画、影片、文件里的人，先确认是谁（看图、看称呼、看前后文、查 `人物对照表.md`），确认了就直接写名字。不写「看样子是」「当是」「疑是」「画面没有署名」「是否同一人没有明说」「定为某某是编者的推断」这类话。确实认不出，就不提身份，只写这个人做了什么。这条只管人物身份；日期的推断照旧写明是推断，来源存疑的事照旧用传闻口吻。

## 人物初见

《史记》立传，开头先说「某者，某地人也」。本书把每个人物的身份写在**人物志**里（`data/annals/人物志/*.md`，每行一人：`名字：身份。`），程序会把它放到每卷此人第一次出场的立条条目下，标作「初见」。

- 身份写此人在本书最早出场时的国别或族群、职务或所属，二十字左右，只写原文或档案能证实的。
- 例：`陈：龙门近卫局警司。`、`霜星：本名叶莲娜，整合运动雪怪小队首领，爱国者养女。`、`玛恩纳：卡西米尔临光家成员，临光之叔。`
- 名字与【人物】里 `[[ ]]` 中的写法一致。剧中另有本名的，在这里注出，【目】里就不必再介绍身份。
- 身份后来有重大变化的（例如离开原属组织、改换阵营），在那一年的条目【目】里交代。
- 一个名字只能在人物志里出现一次；`build` 会列出还没有身份介绍的人物。

## 各字段

**【纲】** 一句，加粗，四十字以内，浅文言。时刻可考者写进纲，写作「清晨七时五十五分」。地点写在纲里。

**【目】** 半文半白，读来顺畅，不堆古字。字数按「收录标准」一节的等级：常事三百字以内，大事四百字以内。目写事情的经过和因果，不转述对白：对白能进【原文】就不进【目】，目里的短引一组不超过三处。
- 只写原文能证实的事。人物原话用「」短引，不要大段转述引文里已有的话。
- 可用「先是」（交代前因）「是日」「既而」「至是」「后」等史书用语，但别每句都用。
- 不评论，不推测动机，不用现代网络语。
- 前因若已在前面的条目写过，一句带过，并按日期参见。
- 人物身份写在人物志里，【目】里不必再介绍。

**【人物】** 在场的当事者，`[[名字]]` 用 ` · ` 隔开；只被提到、没有出场的不列。干员用代号；NPC 用剧中名字，链接里不带头衔（写 `[[麦基]]`，不写 `[[发言人麦基]]`）；只有头衔或编号、没有名字的（「警备队长」「雪怪1号」）不加链接；没有名字的群体不列。

**【原文】** 段数按「收录标准」一节的等级。
- `@引 <分集id> <行号范围> 「锚点」`：行号用 `show` 列出的编号；范围可跳行，写 `12-15,20-22`（中间自动补省略号）；锚点是范围内某行的原文片段，六到十五字，一字不差。
- 每段三到十行，四百字以内；要能单独读懂，选事件发生那一刻或人物最能表态的台词，尽量选说话人有名字的。
- 剧中选项默认署名博士；玩家扮演别人时，在行末加 `选项=名字`。
- 说话人标的名字与实际不符（如戴面具、伪装），在【考异】里说明。
- 干员档案：`@档 <干员> <栏目标题> 「开头」…「结尾」`，取两者之间的全部文字，三百字以内。

**【考异】** 只写有用的，力求简短，一般不超过目的一半：
- 日期的依据（原文写了什么，PRTS 的日期是怎么推出来的；原文没有日期就直说）；改系的理由；
- PRTS 说法与原文不符或说过头的地方，写明原文怎么说；
- 原文前后矛盾、名字异写；
- 出处不在剧本里（设定集《大地巡旅》、网页文案、活动内的报纸文件等）：写「出自……，剧本不载」，能在剧本里找到相关背景的，用一两句交代。
- 年份写作「一〇九七年」。
- 没有把握的推断（某人是否即某人）不写；确有依据的，写明依据。

**互相参见** 本书其他条目按日期指引：「见上年十二月二十三日条」「见三月条」「见五日条」。条目由程序排序，「上条」「下条」只在同一天内使用。引用游戏章节作出处时，可以写「第八章」。

## 核对

- 每条都要对照原文核实，PRTS 的概括常有压缩、误合或说过头的地方。
- 写完运行 `check`，直到没有「!」开头的问题。
- 只改自己负责的文件。

## 体例细则

凡例只列读者要知道的原则，这些细则留给写稿的人。

- 有月日者依日系事，时刻可考者书于纲中。只知月份者书「是月」；只知季节或跨数月者，以「夏」「二月至四月」之类单列；只知其年者，汇于卷末「是岁」，按地域排列。
- 原文与年表不合者，择善而从，改系于原文所示之日；原文毫无日期依据的，才从年表。
- 一〇八〇年以后一年一卷。此前事少而年散，合为四卷：外纪记结晶时代之前，前纪甲、乙、丙记十一世纪前、一〇〇〇至一〇五九年、一〇六〇至一〇七九年，卷内以年为标题。外纪、前纪多出后人转述或设定集，只记可考的大事，不强行系年。原文和年表都无年份的剧情，汇为不系年一卷。
- 纪年称泰拉历。第一座现代移动城市建成之后称结晶时代，这是书中和剧中人的叫法；「结晶纪元」只见于 PRTS 年表，本书不用。
- 人名从游戏：干员用代号，剧中另有本名者于目中注明。剧中只用英文代号、后来实装有汉字名的（逻各斯即 Logos、电弧即 Raidian、机械师即 Mechanist、真言即 Mantra），书中用汉字名，原文片段照旧。人物每卷初见时，略述其国别、身份。
- 同一人只立一页：本名、代号、化名、异格、NPC 转干员，以及巨兽和它唯一的分身，合为一页一传，传中写明转折之事；依据见 `别名依据.md`。
- 剧中由玩家所选的台词标「（选项）」，默认为博士所言；玩家扮演他人时注其名。
- 《大地巡旅》是 E.E. 埃里克森所著、凯尔希手批，引时写明谁说的。《泰拉记事》的文件各有作者和立场，引时写明。
- 集成战略、生息演算的文本多有互斥的结局、梦境和推演，考异注明出处和性质；明确虚构的不入正文。
- 联动活动，年表有条的列于卷末存目；原文仍可在剧本库查看。
- 只听说过而没见到实据的事，纲目用「相传」「或曰」「世传」，考异老实交代只闻其说、未见其本。

## 纪事本末

`data/annals/纪事本末.md` 里每件事以 `@事 名称` 开头，`@线` 列剧情组（故事线），`@加`、`@减` 增删个别事件，其后是三五百字的本末概述。概述只写各条已经证实的事，按时间顺序，不加评论。新卷写完后，看看新条目是否该并入已有的事，或者需要另立一事。

## 列传

`data/annals/列传.md` 里每篇以 `@传 <人物>` 开头（名字与网页人物页一致），其后是三五百字的概述：此人的来历、身份，和在已写各卷中的经历，只写各条已经证实的事。列传收录条目上标了 `传:<人物>` 的条目，按时间排列；此人在其他条目中的出场，另列为「其他出场」。

立传的标准：

- 凡在游戏中当过 Boss（主线章节、活动、集成战略等任何形式），且至少在一章剧情中深度参与（单个剧情组里台词约三十句以上）的，都立传。
- 其余人物，主线核心人物，以及在已写各卷中有完整的起源、转变或结局、故事本身有意思的，也立传。
- 只有零星出场的不立传，他的事归入相关的纪事本末。

列传名单先于各卷开列；一个人的事还没写到时，列传暂时没有条目，网页上不显示。
