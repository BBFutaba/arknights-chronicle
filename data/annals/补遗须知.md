# 补遗须知

项目：明日方舟编年史。全书写完后通读了此前没收进剧本库的文本（集成战略、生息演算、记录点、活动任务和手册），结果在 `data/annals/丛目/壬-*.md`。现在据丛目把内容写进卷稿。主编已逐条定了写什么，见派给你的决定单；决定单之外的候选不写。所有命令在项目根目录运行。

先读 `data/annals/写作规范.md` 全文和 `data/annals/长编须知.md` 的「要求」一节。文风样本：`data/annals/1097/10-长夜临光.md`。

## 怎么写

- **新条目**：写到你自己的新文件 `data/annals/<卷目录>/补遗-<批名>.md`，不要插进别人的文件。按日期排序由程序做。年份卷要写 `系:`；只知年份写 `系:年 是岁:地区`。没有任何时间依据的放 `data/annals/不系年/`，写 `@条 补:名称 不系年 是岁:地区`。合卷（外纪、前纪甲乙丙）的补条要写 `次:ev编号`。补条都是立条：纲、目、人物、原文、考异俱全，有归属（`事:` 或 `传:`），考异写明「年表不载」和日期依据。
- **附记升立条**：就地 Edit 那一条，去掉 `附`，加 `事:`、`传:`，补【目】【人物】【原文】，原考异保留并整理。
- **并入目**：就地 Edit，把事写进现有的目，需要时加一段 `@引`。常事目三百字以内，大事四百字以内，超了就精简，不要堆细节。
- **只补考异**：一两句，写明出处和性质。
- **更正**：照丛目的「更正」改。先看现状，别的代理可能已经改过，改过的不重复。

## 规矩

- 库已重建：**`@引` 的行号一律用 `python -X utf8 -m pipeline.annals show <分集id> [起 止]` 重查**，丛目里的行号可能已偏移，`task/text_xxx:行` 这种是原始文件行号，要换成分集 id 和 `show` 的行号。锚点要一字不差。
- 分清虚实：实事直书；转述写明「某某说」「据某文」；虚构不入正文。集成战略文本的出处和性质，在考异里交代（如「出自集成战略《…》结局文本，其余结局互斥不取」）。拿不准的不写死。
- 不写 PRTS 年表没有依据、原文也没有的话。推断只写在考异里，写明是推断。
- 新人物要有人物志：加到 `data/annals/人物志/补遗-<批名>.md`，每行「名字：身份。」，先 Grep 确认没有重复。
- **不改 `列传.md`、`纪事本末.md`、`别名.md`**，这些由下一道工序统一改，把需要的写进报告。
- 用 Edit 改现有文件，失败就重读再改，**不要用脚本整文件覆写**，别的代理在同时改别处。
- 每写完一个文件运行 `python -X utf8 -m pipeline.annals check <文件>`，直到没有「!」和书法提示。不要运行 `build`，不做 git 操作。

## 交回的报告（中文，简短）

第一行：补条几条、升立条几条、并入几处、补考异几处、更正几处、跳过几处。然后：
1. 新文件和新条目名。
2. 跳过的和理由。
3. **给列传阶段**：每位人物一行，写清这人要补什么事、哪个条目（新立的传也列）。纪事本末要补的同样一行一件。
4. 要加的别名；系日有疑的。没有就写「无」。
不要编造结果，核不了的如实写。
