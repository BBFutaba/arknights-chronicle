# 删定须知

全书初稿已成，长编偏长。你负责压缩指定卷稿的【目】，并统一文风。司马光修《通鉴》时「删长编为定本」，就是这一步。

先读 `data/annals/写作规范.md` 的「书法」「各字段」两节。

## 要求

- 用下面的命令列出超长的组（目超过三百字），只改这些组。别的组不动。
  ```
  python -X utf8 -m pipeline.annals long data/annals/<年>/<文件>.md
  ```
- 常事压到三百字以内，大事（关乎国家势力兴衰、主要人物生死去留）四百字以内。
- 删什么：转述对白的句子（尤其是【原文】里已经引了的）；过程里的枝节；重复前文的交代；只为凑完整的动作描写。
- 留什么：事情的因果和转折；人物的选择；后文要用到的伏笔；日期、地点、人名。
- **只改【目】。** `@条` 行、【纲】、【人物】、【原文】、`@引`、【考异】一律不动。
- **不查剧本，不加新事实，不改事实。** 只做删减和必要的连缀。短引「」只能保留原有的，不能改字。
- 文风：半文半白，读来顺畅，不堆古字，不用现代网络语。「先是」「是日」「既而」别每句都用。人称要清楚，「他」指谁读者不能猜。
- 用 Edit 工具逐组改；不要用脚本批量替换，也不要整文件重写。每改完一个文件运行 `python -X utf8 -m pipeline.annals check <文件>`，直到没有「!」和书法提示。不要运行 `build`。

## 交回的报告

一句话：改了几组，各文件前后字数。发现的事实矛盾、人称错误另列，没有就不写。
