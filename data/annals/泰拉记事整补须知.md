# 《泰拉记事》整补须知

上一轮整补（`整补须知.md`）时《泰拉记事》没有原件，靠它的说法都写成了传闻口吻（「编者只闻其名」「相传」）。现在原件到手，也归档了。这一轮把这些说法核实，再把新事实补进去。

先读 `凡例.md`、`写作规范.md`、`整补须知.md`（四种情况和道听途说的口吻，这里照用），写新条目再读 `补遗须知.md`。命令在项目根目录运行。

## 材料

- 归档：`Raw Data/泰拉记事/归档-甲.md` 到 `归档-己.md`。每个文件末尾有**对书核对表**（`文件:行 | 书里的说法 | 判定 | 篇与切片 | 短引`）、**书里没有的新事实**、**博物线索**。用 Grep 按你的文件名和词条名搜这六个文件。**归档是起点，不是结论**：归档者可能读错，行号可能已偏移。
- 原件：`Raw Data/泰拉记事/<编号> <日期> <篇名>/`，`ocr.txt` 是文字，`切片/NN-kk.jpg` 是图，`说明.txt` 是微博配文。所有 OCR 合在 `Raw Data/泰拉记事/全文.txt`。**改之前读原件**，短引必须对过切片。
- 书里其他材料照旧：`python -X utf8 -m pipeline.annals rawfind "词"`、`show <分集id> [起 止]`。

## 要点

- **文件夹名上的日期是微博发布的现实日期，不能用来系年。** 只看文件里明写的，或能推出的。
- **文件是剧中人写的，各有立场。** 写清谁写的：「判决书说」「克莱门莎报告」「多萝西的邮件写」，不要写成「泰拉记事载」。官方报告、报纸、宣传册的口径和剧本不同时，以剧本为准，把官方口径记进考异，这本身就是史料。比如《新都会，新狂欢！》说安东尼奥「仍下落不明」，剧本是卡尔铳杀了他。
- **「泰拉那些事」多是玩笑小品，不入史。** 归档判为玩笑的不用。微博配文（`说明.txt`）也是官方文字，但不是剧中文件，引时说明。
- **PRTS 年表不算证实。** 归档发现年表把别的出处也注到《泰拉记事》名下的，比如莱茵生命的博士学位、入伙，《调查报告01》里其实没有，出处仍是《大地巡旅》，这些不能改口说「报告证实」。
- 引法：「事见《泰拉记事·大理寺密卷》」。短引只录一两句，一字不差。
- 全书不再出现「编者未见」「只闻其名」，除非指的是 ORACLE DATABASE 这类确实没有的东西。证实了的「相传」要去掉。
- 只有部分证实的，证实的写实，没证实的细节仍用传闻口吻，或者从纲目里去掉。比如麟青砚入大理寺只能证到一〇九七年，「正月」无据，就不要留在纲里。
- 推断写明是推断。

## 主编已定的几件事

- **马特托**是年表笔误，应作马特维（学生联合大会档案，尤拉残页）。ev0694 的年份放宽到约一〇九九年冬至一一〇〇年初。
- **ev0739**：修道院一月二十五日还在路上，二月二十一日才回到拉特兰（主教的日记）。纲和系日照改，记明年表原系。
- **十科成型**在一〇九二年（调查报告01），不是一〇九六年。
- **ev0800**：八月十四日新地块投入使用，日志明写；但「最后一个地块」「广播」不在日志里，和结局四算作同一天是推断，考异写明。
- **ev0907**：九月三十日判决证实，虞澄十年、解真六年。判决书定解真动手、虞澄主谋；顾筌之死，判决书作「唆使自杀」，书作坠河，两说并列，判决书是官方结论，不等于真相，看原文后择善而从。判决书的「八月十五」可能是阳历，这是推断，写进考异，不改系，但要复核 ev0906、ev0907 的先后。
- **ev0665**：绝密通信不提苇草、爱布拉娜和演说，这几节仍是传闻口吻；它能证的是七月舰队北上和开斯特公爵亲笔放行。
- **开斯特公爵是女性**。你的文件里凡写成「他」的，都要改。

## 新事实怎么立

和上一轮一样：有推动的（人物来历、身份、理念，势力兴衰，制度更替）才立，只见于书外的事只书纲，写到 `data/annals/<卷目录>/补遗-泰拉记事.md`，写法 `@条 补:名称 系:… 附`，只有【纲】和【考异】，能算进某件本末的加 `事:本末名`，某个人的加 `传:名字`。书里已有的事多了细节，就并进现有条目的考异。纯设定细节归博物志。

## 规矩

- 只改分给你的文件，加上你那些卷的 `补遗-泰拉记事.md`。**不改 `列传.md`、`纪事本末.md`、`别名.md`、`人物志/`、`列传索引-*.md`、别组的文件**。
- 要给列传、本末、人物志、别组文件的改动，写到分给你的线索文件 `Raw Data/泰拉记事/线索-<组>.md`，每行一条：写清改谁、改什么、依据哪一篇哪张切片或哪个条目。
- 用 Edit 改，失败就重读再改。每改完一个文件运行 `python -X utf8 -m pipeline.annals check <文件>`，直到没有 `!`。不运行 build，不做 git 操作。
- 文风别动。埃里克森和凯尔希的口吻照旧。幽默要干。
- 不编造。核不了的如实写。
