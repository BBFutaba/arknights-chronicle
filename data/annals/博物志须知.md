# 博物志须知：格式和校验

博物志是网页的一个栏目，收地理、势力、族裔、源石、科技、人文、生灵、远古八门的百科内容。稿件放在 `data/annals/博物志/*.md`，一个门一个文件（文件名不限，门由条目声明）。

## 编辑原则

**收什么。** 读者读编年史和列传时，不解释就读不懂的词；全部地区势力；以及能帮人理解这个世界的地理、风俗、制度、技术、生物。只是好玩、和世界理解无关的冷知识不收。联动活动的内容不收。

**只写材料里有的。** 每句话都要能指到出处：剧本、档案、《大地巡旅》、官方影片、官方漫画、《泰拉记事》。**不要凭自己的记忆或别处看来的设定写**，哪怕你很确定。`pipeline.annals rawfind` 和 `Raw Data/` 下的 OCR、归档都查不到的，就不写。

**分清谁在说话。** 这是博物志最要紧的一条：

- `【释】` 是编者的话，只写各方都不争的部分。
- `【说】` 记各家说法，一律写明出处和说话人。某国人的偏见、某个学者的假说、罗德岛的立场、传说故事，都按原样记成某人的说法，不要提升成事实。说法相左就并列，不替他们裁决；能裁决的写在考异，写明依据。
- 材料可信程度大致是：游戏世界观提示和剧情叙述 > 官方文件和档案 > 人物台词（看说话人立场）> 官方影片的传说讲述 > 集成战略文本（先分虚实）。《萨卡兹的无终奇语》多出妮芙之口，除非有旁证，一概不据；正史不载而值得一记的，可以写成「据野史记载」，语气略带戏谑，不作定说，写法见[[奎隆]]。

**《大地巡旅》的口吻要留着。** 这本书是世界观里的老学者 E.E. 埃里克森写的，又有凯尔希的手写批注，两个人都不是我们这个世界的作者。所以：

- 把他们当剧中人引，不当「设定」引。写「埃里克森说」「他抱怨」「凯尔希在页边批道」，不写「设定集记载」。
- 引文挑有风味的句子：他的絮叨、偏见、自嘲，她的冷淡和纠正。两人意见不合的地方最值得录。
- 编者可以跟着带一点这种趣味，干巴巴地点一句即可，不要写成段子。事实部分照旧要准。
- 埃里克森也会错，也有他那个年代的局限。书的内容大致止于一〇九九年前后，和后来的剧情不合时，以剧情为准，在考异注明。

**书法。** 编年史的中性书法照旧，人名按 `人物对照表.md` 统一，年份写「一〇九八年」这种汉字。《序言组曲：火与路》留作备用，不引。

**篇幅。** 小条一两百字，大国和大组织四百到八百字。每条短引三五句为限，每句不超过三十字左右。这里是摘录点评，不是转载。短引要对照原图核对字词，因为 OCR 有错字。

**写好以后**，`check` 无 `!`。交回时列出：新写了哪些条目、没有写成的和原因、建议别的门补充的词。

## 校验

都在项目根目录运行。

```bash
python -X utf8 -m pipeline.annals check data/annals/博物志/<文件>.md   # 检查一个文件
python -X utf8 -m pipeline.annals build                                # 检查全书，导出网页数据 site/data/bowu.json
python -X utf8 -m pipeline.annals quotes <输出文件>                    # 核对全书短引，博物志也在内，比较慢
```

输出里 `!` 开头的是错误，要改；`~` 开头的是提示，看一眼就行。

查原文用的命令：

```bash
python -X utf8 -m pipeline.annals show <分集id> [起 止]    # 带行号列出一集剧本，@引 的行号从这里来
python -X utf8 -m pipeline.annals find "<正则>" [组id]     # 在剧本里搜索
python -X utf8 -m pipeline.annals rawfind "<正则>" [上限]  # 在全部游戏文本里搜索，默认列 60 处，0 是全部；被截断时会说，下「没有」的判断之前要看全
```

## 条目

每条以一行 `@物` 开头，后面是若干字段。`#` 开头的行和 `<!--` 开头的行是给人看的，程序跳过。

```
@物 移动城市 门:科技 别:移动城邦,城邦 关:rhodes,lungmen 上:工业科技
【释】用编者自己的话说它是什么。可多段。
【说】各家说法，写明谁说的。可多段。
【沿革】可选。
【见】条:ev0123,ev0456 传:塔露拉,陈 事:整合运动 物:源石
@引 <分集id> 12-14 「锚」
@档 <干员名>·<档案节名> 「锚」
@书 大地巡旅 p.044 埃里克森 「短引」
@书 大地巡旅 p.044 凯尔希批注 「短引」
@影 追溯泰拉 01:00 旁白 「短引」
@漫 序言组曲：旧创 二话 p012 拉普兰德 「短引」
【考异】可选。出处和疑点，网页上默认收起。
```

### `@物` 这一行

| 写法 | 必填 | 意思 |
|---|---|---|
| `名字` | 是 | 条目名，也是网址里的名字。可以带空格（`Ave Mujica`），到第一个选项为止。全书不能重名。 |
| `门:` | 是 | 地理、势力、族裔、源石、科技、人文、生灵、远古，八选一。 |
| `别:` | 否 | 别名，逗号隔开。搜索和「书中提及」都算；别名也不能和别的条目重复。 |
| `关:` | 否 | 关联的地区势力，写 id，逗号隔开。id 是 `site/data/powers.json` 的键（`rhodes`、`lungmen`、`x_卡兹戴尔`……）。 |
| `上:` | 否 | 上级，写别的条目名或地区势力的名字。同门的上级在目录里缩进；上级在别的门，目录里算顶层，页面上写明上级。地区势力本身的上下级不用写，自动沿用。 |

### 一地一页：`关:` 怎么算

全部 50 个地区势力都列在地理、势力两门，每个只有一页。还没有条目的，页面只有原来的资料（上级、下属、成员、年表事件、提及的剧情），并标「尚未成文」。

一个条目在两种情况下就是某个地区势力的页面，正文在上，资料接在下面：

1. 条目名或别名就是地区势力的名字，要写上对应的 `关:`（否则报错）：`@物 龙门 门:地理 关:lungmen`。这种条目的门只能写地理或势力，比如汐斯塔可以从势力改放到地理。
2. 名字不同，但在地理或势力门，只写了一个 `关:`，也没写 `上:`。

其余写了 `关:` 的条目只是相关条目，比如 `@物 移动城市 门:科技 关:rhodes,lungmen`：自己的页面下方有可以展开的「相关的地区势力」，罗德岛和龙门的页面下方列出这一条。两条都想当同一个地区势力的页面时，第 1 种优先，其次按文件顺序，`check` 会提示。

### 字段

- `【释】` 必填。用编者自己的话说它是什么。可多段，每行一段。
- `【说】` 各家说法，写明谁说的。
- `【沿革】` 可选。
- `【见】` 去处，可以多行，值用逗号隔开，中间不能有空格。`条:` 写事件编号（`ev0123`，或补条的 `补:名称`），能点到编年史；`传:` 写人物，有列传到列传，没有到人物页；`事:` 写纪事本末的标题；`物:` 写博物志的别的条目或地区势力。
- `【考异】` 可选。默认收起。`- ` 开头的行是列表项。

正文里 `**加粗**` 和 `[[名字]]` 可用：`[[名字]]` 先找人物，再找博物志条目和地区势力，都没有就只显示文字，`check` 会提示。

### 引文

引文指令写在 `【说】`、`【沿革】`、`【见】` 里，放在哪段后面，网页上就显示在哪里。`【考异】` 里不放。

| 指令 | 写法 | 校验 |
|---|---|---|
| `@引` | `@引 <分集id> <行号> 「锚」`。行号可写 `12-18` 或 `12-18,25-27`，是 `show` 列出的编号。玩家扮演别人时在行末写 `选项=Scout`。 | 严校验：分集和行号要存在，锚点要出现在这几行里，过长报错。网页上能点到剧情页。 |
| `@档` | `@档 <干员名>·<档案节名> 「锚」`，或 `「开头」…「结尾」` 引一段。也接受 `@档 <干员名> <档案节名> 「锚」`。 | 严校验：节名和锚点要存在。 |
| `@书` | `@书 <书名> p.<页> <说话人> 「短引」`。页码按书上印的写，`p.044`；前言这类写 `p.IV`，没有页码的写 `p.扉页`。说话人可以不写。 | 模糊比对 `Raw Data/<书名>/全文.txt`。 |
| `@影` | `@影 <片名> <时间> <说话人> 「短引」`。时间写 `01:00` 或 `01:00-01:20`。片名写字幕文件名里有的那段就行，比如 `追溯泰拉`、`炎：劫争`。 | 模糊比对 `Raw Data/视频/字幕/*.txt`。 |
| `@漫` | `@漫 <书名> <话> p<页> <说话人> 「短引」`，比如 `@漫 序言组曲：火与路 下篇 p059 塔露拉 「……」`。书名中间不要有空格。 | 模糊比对 `Raw Data/漫画/*/ocr.txt`。 |
| `@记` | `@记 <篇名> <说话人> 「短引」`，《泰拉记事》的篇目，比如 `@记 大理寺密卷 虞澄 「……」`。篇名写文件夹名里有的那段，中间不留空格，不带「」；说话人可以不写。 | 模糊比对 `Raw Data/泰拉记事/*/ocr.txt`。 |

书外引文（`@书`、`@影`、`@漫`、`@记`）：

- **只录短句。** 超过八十字 `check` 会提示。全文不进网页数据，也不进公开版，只有条目里写的短引进。
- **模糊比对只是防手误。** 那些全文是 OCR，有错字，所以只算字符重合度，低于七成才给 `~` 提示，不算错误；文件还不存在就跳过，`check` 的末尾会说跳过了几处。短引的字词要对照原图核对。
- 中间省略用 `……`，每段分开比对。
- `@书 … 埃里克森` 网页上署「E.E. 埃里克森」，用印刷书页的样式。说话人以「批注」结尾的（`凯尔希批注`）用手写批注的样式。别的说话人（`叶先生`）用普通引文样式，署所写的名字。
- **不猜人物身份。** 漫画、影片、文件里的人，先确认是谁（看图、看称呼、看前后文、查 `人物对照表.md`），确认了就直接写名字。不写「看样子是」「当是」「疑是」「画面没有署名」「是否同一人没有明说」「定为某某是编者的推断」这类话。确实认不出，就不提身份，只写这个人做了什么。这条只管人物身份；日期的推断照旧写明是推断，来源存疑的事照旧用传闻口吻。

## 书中提及

每个条目底部的「书中提及」由程序统计：编年史的纲、目和列传概述里，出现条目名或别名的地方。纲里写到的优先，其次写得多的，最多列十条纲目、四篇列传，其余只计总数。单字的词不统计，太容易误配；所以单字名字的条目（炎、东、岁）要写一个两字以上的别名，才统计得到。炎、东两个地区的 `炎国`、`东国` 程序已经知道。

## 分组撰写时的约定

- 只写分给你的词，写到分给你的文件。别的组写的词不重复，要提到就用 `[[名字]]` 链过去，哪怕对方还没写好（`check` 的提示可以忽略）。
- 材料都已备好。先读 `Raw Data/大地巡旅/归档/` 里对应的卷、`Raw Data/视频/归档-世界观.md` 和 `Raw Data/视频/归档-特别映像.md` 的「博物志素材」节。用 Grep 在这些归档里搜词。然后**一定要搜游戏原文**：`python -X utf8 -m pipeline.annals rawfind "词"`，书稿也要查（`data/annals/列传.md`、各卷）。很多最好的解释藏在干员档案和剧情台词里，比如「圣徒」的两个意思都写在送葬人异格的档案资料四。
- 归档里的短引有的标了已对图，有的只据 OCR。写进条目前，没对过图的要看 `Raw Data/大地巡旅/页/p-NNN.jpg`（PDF 页号 = 书页 + 8，个别地方有偏差，以图上印的页码为准）。影片短引不确定时，用 `python C:/Users/acgnm/.claude/skills/video-download/scripts/bili.py frames` 抽帧看。一条消息并行读几张图，不要一张一条消息。
- `【见】` 里的事件编号、传名、本末名都要用 Grep 查证存在，不要写没有的。
- `关:` 的 id 查 `site/data/powers.json`。
- 不改书稿，不改别人的文件，不运行 build，不做 git 操作。每写完几条就 `check` 一次。
