# 刻舟录 · 路线图

目标：写成一部覆盖全部剧情的编年史。编年为骨架，纪事本末（按事）、列传（按人）为经纬；所录之事都要对人或事有推力。体例见《凡例》，写法见《写作规范》。

## 每一卷的工序

仿司马光修《通鉴》的「丛目、长编、删定」三道工序，再加复盘：

1. **丛目**：先不看 PRTS，用 `python -m pipeline.timeclues` 提取的时间线索（场景抬头、明写日期、「几年前」）和各集简介，把这一年涉及的剧情组、分集按时间排出来，写进 `data/annals/丛目/<年份>.md`：每个剧情组系于何时、依据是什么；再与 PRTS 年表对照，列出两边不一致的地方，以及年表没有覆盖、但对人或事有推力的剧情（补条候选）。`timeclues gaps <年份>` 列出待审的分集。
2. **长编**：按故事线分派子代理写卷稿（`data/annals/<年份>/*.md`），每条定去处（立条、附记、存目）、标归属（`事:`、`传:`）、写人物志、系日以原文为本，丛目里的补条候选一并处理。
3. **统稿**：合稿、`build`；处理归属、书法、初见的提示；更新纪事本末和列传的概述；在网页上通读。
4. **复盘**：分析这一卷的问题，改进规范和工具，再进入下一卷。

全书写完后，再做一道**删定**：压缩长编，统一文风。

自一〇九九年卷起用收紧的做法（用户已同意，全书写完前不再请示）：
- 丛目只靠时间线索和官方简介，必要时才读原文，用便宜的模型；把年表事件出处只写组名的那些组也列进去。
- 长编不必通读全组：先看丛目和简介，只读要立条、要引用、要核实的集；分工说明和收紧后的要求见 `长编须知.md`。主线和大事用默认模型，散事和小线用便宜的模型。
- 目的字数、补条的多少，见写作规范。
- 列传概述不再每卷续写：主线写完（一一〇三年）时写一遍，前纪、外纪写完后再补一遍，省得反复重写。纪事本末概述仍每卷续写。

## 阶段目标

1. **定型**：一〇九六、一〇九七两卷按新标准修订完成，列传名单、人物志、丛目工具就位，复盘后定稿规范。
2. **主线贯通**：写完一〇九八至一一〇三年，主线第九至十七章和同期活动全部入编年；纪事本末覆盖维多利亚之乱、卡兹戴尔、莱塔尼亚、叙拉古、伊比利亚等大事。
3. **前史**：写完前纪、外纪；列传补齐人物的早年经历。
4. **删定**：全书统一删定，补全纪事本末和列传的概述。

## 丛目的格式

`data/annals/丛目/<名称>.md`，每个剧情组一节：

```
## main_9 风暴瞭望
系年：一〇九七年秋至一〇九八年春。依据：……（场景抬头、「几年前」等，注 分集id:行号）
PRTS：本线事件 1097×2、1098×2。与原文的出入：……
分集：
- main_9_level_st_09-01 9-1 幕间：一〇九七年秋，小丘郡；一句事由。〔年表 ev0590〕〔编年已引〕
- …
补条候选：
- main_9_level_main_09-05_end：一句事由。推力：事之因果（维多利亚之乱）。拟系：一〇九七年秋。
```

整组的「现在」不在所查年份、只是回忆到这几年的，写一行系年和涉及的回忆分集即可。
