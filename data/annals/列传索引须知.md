# 列传索引须知

网页上「列传」单独成一个标签，要能按出身、盖棺等方式查找。你负责分给你的那部分人，逐人查证，把索引写好。这份索引会公开，读者会靠它找人，一个「已盖棺」写错就是大错。

## 文件

`data/annals/列传索引-<组>.md`，一行一人，竖线分列，`#` 开头的是说明：

```
名字 | 出身 | 出身详 | 族裔 | 所属 | 盖棺 | 卒 | 条 | 注 | 据
```

文件已经预填好了名字，干员的出身、族裔、所属也从基础档案填进去了。预填只是起点，要核对；传主是 NPC 的基本都是空的。用 Edit 改，保持一行一人。

## 各列

- **出身**：这个人**生长、来历所在**的地区，只能写一个，取值见下。不是后来效力的地方：卡兹戴尔出身、在罗德岛当干员的写卡兹戴尔。
  取值：乌萨斯、炎、东、维多利亚、塔拉、卡西米尔、莱塔尼亚、拉特兰、叙拉古、伊比利亚、阿戈尔、玻利瓦尔、哥伦比亚、米诺斯、雷姆必拓、谢拉格、萨尔贡、萨米、卡兹戴尔、汐斯塔、罗德岛（生长在舰上的）、前文明（普瑞赛斯这类）、深海（海嗣这类）、未详。
  基础档案的【出身地】是官方的说法，但有的写「未公开」，有的和剧情不同（剧情说了真实来历的，以剧情为准，写在「据」里）。「龙门」写炎，「切尔诺伯格」写乌萨斯，「伦蒂尼姆」写维多利亚，原来的写法放到「出身详」。真查不到写未详，不要猜。
- **出身详**：可空。比如 `龙门`、`切尔诺伯格`、`谢拉格耶拉冈德山下`。短。
- **族裔**：基础档案的【种族】，写主要的一个（`卡特斯/奇美拉` 写 `卡特斯`）；NPC 查人物页简介、列传、剧情和 `data/annals/人物对照表.md`。查不到留空。
- **所属**：最能说明这个人身份的势力，一到两个，顿号隔开。优先用博物志条目名（`Grep "@物 名字" data/annals/博物志`），比如 `整合运动`、`莱茵生命`、`司岁台`、`无胄盟`。没有更具体归属的干员写 `罗德岛`；有更具体的写具体的，真正重要才带上罗德岛。
- **盖棺**：字面意思，这个人死了没有。只能写：
  - `已`：书中写明身死。遗体、葬礼、死讯、亲历者的话都算，要可靠。死后在回忆、梦境、幻象里再出现，仍是已。
  - `未`：到最后一次出场还活着。
  - `未卜`：下落不明、坠落失踪、只有传闻死讯而没有实证。
  - `异数`：常人的生死说不清：死而复生、诈死之外的还魂、意识转移、躯壳被占据、分身、机械或巨兽的存续。在「注」里写一句到底怎么了。
- **卒**：盖棺为 `已` 时必写，写书中的日子，用书的写法：`一〇九七年正月四日`、`约一〇九一年`、`不详`。其他情况留空。
- **条**：记载这个人身死（或异数那件事）的那一条，写 `ev0551` 这样的编号；补条写它的锚点（Grep 卷稿里的 `@条 补:名称`，写法见下）。没有就留空。
- **注**：可空。一句话，网页上会显示。`已` 通常不用写。`未卜`、`异数` 必写。
- **据**：必写，只留在稿件里，给核对的人看。`已`、`未卜`、`异数` 写身死或失踪那件事的出处：`分集:行`、卷稿 `ev` 号，或档案名。`未` 写最后一次出场：`分集 或 ev，那时在做什么`。出身不是抄基础档案的，也写在这里。

补条的锚点：运行 `python -X utf8 -c "import json;a=json.load(open('site/data/annals.json',encoding='utf8'));print([e['id'] for v in a['volumes'] for s in v['sections'] for d in s['days'] for e in d['entries'] if '<名字>' in str(e['groups'][0]['gang'])])"`。

## 怎么查

1. 读 `data/annals/列传.md` 里这个人的那一篇。
2. 列传没写结局的，要往下查，不要默认活着：
   - `python -X utf8 -m pipeline.annals zhuan <名字>` 列出这个人的条目，看最后几条。
   - `Grep "<名字>" data/annals` 看卷稿。
   - `python -X utf8 -m pipeline.annals rawfind "<名字>"` 搜原文；再搜「<名字>死」「<名字>的葬礼」「悼念<名字>」「<名字>牺牲」这些说法。需要时用 `python -X utf8 -m pipeline.annals show <分集id> <起> <止>` 读上下文。
3. 特别当心：
   - **诈死**：写 `未`，注里说明。比如假死脱身、换脸改名的。
   - **集成战略、生息演算、活动梦境、推演、互斥结局**里的死亡不算，凡例说它们要看性质。
   - **联动活动**不入正史，里面的事不算。
   - **同名和异格**：一人一页，异格和本人是同一个人。
   - **旁人的说法**：「据说他死了」只能算未卜。
   - **活人被写成「已故」的档案**和**死人还在档案里说话**的情况都有，档案的时点可能早于死亡。以时间最晚的可靠记载为准。
   - **《火与路》**还没入库，不用管。

## 规矩

- 只改分给你的 `列传索引-<组>.md`，不改列传、卷稿和别的文件。不运行 build，不做 git 操作。
- 改完运行 `python -X utf8 -m pipeline.annals idx data/annals/列传索引-<组>.md`，直到没有问题。
- 不要编造。查不到就写未详、留空，或写 `未卜` 并说明。
