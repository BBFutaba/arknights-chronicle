# 整补须知

项目：明日方舟编年史（`data/annals/`）。全书写成时，出自书外的内容（设定集《大地巡旅》、官方影片、官方漫画）都没有原件，考异里留了很多「未能核对原书」。现在这些材料到手了。整补要做两件事：**能证实的就坐实，补不了的改成道听途说的口吻**。全书整补完，不再出现「未能核对」这种编辑部用语。

先读 `凡例.md`、`写作规范.md`，再读 `补遗须知.md`（新条目怎么写）。

## 材料

- 线索：`Raw Data/整补线索.md`，各组顺手发现的问题，也要逐条核。
- 误读：归档有误读，以 `data/annals/博物志/*.md` 文件头和考异、`Raw Data/整补线索.md` 末尾为准。官方勘误见 `Raw Data/大地巡旅/勘误.txt`。
- 原件：书的 OCR 全文 `Raw Data/大地巡旅/全文.txt`，页图 `Raw Data/大地巡旅/页/p-NNN.jpg`（PDF 页 = 书页 + 8，个别有偏差）。影片字幕 `Raw Data/视频/字幕/`。漫画 `Raw Data/漫画/*/ocr.txt`。

- 《泰拉记事》（微博图文）这一轮没有拿到原件。后来到手了，核实见 `泰拉记事整补须知.md`；下一节提到它的例句只是当时的写法，不要再用。

## 每一处怎么改

先把这一条对应的原文读到，不要只看核对表。然后四种情况：

**证实。** 删掉「未能核对」，写明出处和页码或时间戳：「出自《大地巡旅》5.18「东国来信」（书页 327）」。如果书里有更准的细节，纲、目照改。可以带一小句原话，埃里克森和凯尔希是书中人，就写「埃里克森说」「凯尔希批道」，不写「设定集载」。

**部分证实。** 证实的部分照上面写。没有证实的细节按第四种处理；如果那个细节站不住，就从纲、目里去掉。

**不同。** 并列双方原话，按凡例「择善而从」。纲目写错的就改，考异记下原来的说法和改动的理由。凯尔希批注否定埃里克森的（比如塔拉的「合并」），两说都留，写明她的话。官方影片里的传说、寓言、广告不等于史实，要看性质。

**材料补不了。** 改成道听途说的口吻，见下节。

## 道听途说的口吻

这是用户明确要的：像一个老派编者，只听人说过，没见过实据，老实交代，还带点无奈。

- **考异**里，把「未能核对原书」换成这种话，意思要准确，告诉读者这事靠不靠得住：
  - 「此说只闻于年表，编者遍检手头诸本不见，姑存之。」
  - 「世传如此，未见所本。」
  - 「事见《泰拉记事·大理寺密卷》，编者只闻其名，未见其书，姑从年表所转。」
  - 「编者也是听来的，信否由人。」
  - 「或曰如此，未知所本。」
- **纲、目**里，如果整件事只有这种来源，叙述也要带上：「相传」「或曰」「世传」「据传」「传闻」，开头一个词就够，不必每句都加。
- 这些只是样子，可以换说法。一卷之内不要反复用同一句。
- **不要**编造传话人（「一位老商人说」「某学者考证」），不要编造来源。只有口吻是编的，事情和来源不能编。
- 口吻只用于真正查不到的事。查得到的不要偷懒写成传闻。
- 书法的其他部分照旧中性，这种语气只用于来源存疑这一点。幽默要干，一两句带过，不写段子。
- 妮芙相关的吐槽已经写好，不用再加。

类似说法都要处理：未能核对、未核对、未能核实、未见原书、无从印证、未证实、未详所本。「剧本不书年」「原文不书」这种是说原文没写，不是存疑，保留。但如果新材料写了，就补上。

## 新事实

归档里「书里没有的新事实」，有推动的（人物来历、身份、理念，势力兴衰，制度更替）才立。

- 按凡例，只见于书外的事只书纲，于考异注明出处；写到新文件 `data/annals/<卷目录>/补遗-整补.md`，不要插进别人的文件，写法是 `@条 补:名称 系:… 附`，只有【纲】和【考异】（程序已放宽，补条可以是附记）。没有年份的放 `不系年`，或按凡例写进外纪、前纪。
- 推断的年份写在考异，写明是推断。
- 书里已经有的事只是多了细节，就并进现有条目的考异，或者目（如有必要），不要另立。
- 纯设定细节归博物志，不入编年。

## 规矩

- `@引` 的行号用 `python -X utf8 -m pipeline.annals show <分集id> [起 止]` 查，不要猜。
- 用 Edit 改现有文件，失败就重读再改，不要脚本整文件覆写。
- **不改 `列传.md`、`纪事本末.md`、`别名.md`**，把需要改的写进报告，由下一道工序统一改。
- 每改完一个文件运行 `python -X utf8 -m pipeline.annals check <文件>`，直到没有「!」和书法提示。不要运行 build，不做 git 操作。
- 不编造。核不了的如实写。
